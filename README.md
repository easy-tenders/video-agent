# Видео-агент Алии — монтаж роликов с ИИ

Агент для Claude Code монтирует вертикальные ролики (Reels, TikTok, Shorts) из того, что
снято на телефон: расшифровывает речь, режет паузы и оговорки, ставит наезды для ритма,
выравнивает звук, делает субтитры и надписи, собирает 1080×1920 и сам проверяет результат.
Всё считается на вашем компьютере — **ключей, подписок на сервисы монтажа и оплаты за
ролик не нужно**. Нужна только ваша подписка Claude.

## Что нужно

- Компьютер на **Windows 10 или 11**, ~5 ГБ свободного места.
- **Приложение Claude** с вкладкой Code (Claude Code) — вход вашей учётной записью Claude.
- **Git for Windows** — https://git-scm.com/download/win (Claude Code запускает через него
  команды; при установке все пункты по умолчанию).
- Доступ к этому репозиторию на GitHub (приглашение приходит на почту).

Python, ffmpeg и шрифт ставятся сами на шаге 2.

## Установка — один раз

1. Скачать папку. В терминале Git Bash:
   ```sh
   cd /c
   git clone https://github.com/easy-tenders/video-agent.git
   ```
   Папка ляжет в `C:\video-agent` — ближе к корню диска, не в «Документы».
2. Открыть `C:\video-agent\bin` и дважды щёлкнуть **`setup.cmd`**. Он через winget ставит
   Python 3.12 и ffmpeg, окружение движка и шрифт Inter. 5–10 минут. Если попросит закрыть
   окно и открыть заново — закрыть и запустить `setup.cmd` ещё раз.
3. В приложении Claude, вкладка Code, открыть папку `C:\video-agent`.

## Первый ролик

1. Положить видео с телефона в `C:\video-agent\video\inbox\`.
2. Написать агенту: **«смонтируй ролик из video/inbox»** — и в двух словах, что за ролик:
   что оставить, какие надписи на экране, нужны ли субтитры.
3. Агент покажет, что понял из речи, соберёт ролик и проверит его.
   Готовый файл — `C:\video-agent\video\projects\<ролик>\out\reel.mp4`.

Первый ролик дольше: модель расшифровки (~1,6 ГБ) скачивается один раз. Дальше минута
видео расшифровывается примерно за минуту.

Правки — обычными словами: «убери кусок про цены», «субтитры крупнее», «поменяй порядок».
Агент пересоберёт ролик за пару минут.

## Что умеет и чего нет

- **Умеет:** говорящая голова и голос за кадром, запись экрана рядом с лицом, субтитры
  двух стилей, надписи-карточки, музыка (только с указанной лицензией), звуковые акценты,
  контактный лист — раскадровка для проверки глазами.
- **Нет:** генерации видео, обложек, автопубликации — публикуете вы сами.

## Если что-то не так

Написать агенту, что случилось, — он разберётся сам. Не получилось — написать Скандару.

## Ваши данные

Видео в git не уходит: в репозитории хранится только монтажный лист `edit.json` ролика.
Ролики, исходники и готовые файлы лежат только на вашем компьютере.
